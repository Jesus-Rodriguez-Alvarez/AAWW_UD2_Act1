Catálogo Completo de Proyectos

A continuación se detallan los aspectos técnicos, configuraciones y aprendizajes de las principales prácticas realizadas en el ámbito de Administración de Sistemas Informáticos en Red (ASIR):

1. Prácticas en U-tad: Proyecto "Radio U-tad" (Departamento de Métricas)

Grafana Prometheus Radio U-tad Monitorización de Servidores Prácticas U-tad

Descripción: Participación activa durante las prácticas en U-tad integrándome en el departamento de métricas del proyecto interdisciplinar "Radio U-tad". El objetivo principal fue desplegar y administrar la infraestructura de monitorización de rendimiento de los diferentes servidores encargados de la emisión, procesamiento y almacenamiento del proyecto.

Responsabilidades y Logros Clave:

  • Despliegue de Prometheus: Configuración de recolectores de métricas (node_exporter y exporters de servicios) en los distintos servidores de la infraestructura para capturar datos de CPU, memoria RAM, E/S de disco y tráfico de red en tiempo real.
  • Diseño de Dashboards en Grafana: Creación de cuadros de mando visuales e interactivos para analizar el estado de salud, uso de recursos y tendencias de rendimiento de los servidores.
  • Gestión de Alertas y Métricas: Definición de umbrales y reglas de alerta automatizadas para notificar al equipo ante cualquier anomalía o degradación del servicio en los servidores de Radio U-tad.

2. Infraestructura de Red Corporativa en Cisco Packet Tracer

Cisco Packet Tracer VLANs Subnetting VLSM Inter-VLAN Routing

Descripción: Diseño e implementación de la topología de red para una PYME dividida en diferentes departamentos (Administración, Ventas, IT y Servidores).

Puntos Clave:

  • Segmentación de tráfico mediante VLANs 10, 20, 30 y 99 (Gestión).
  • Enrutamiento Inter-VLAN mediante subinterfaces en Router (Router-on-a-Stick).
  • Configuración de DHCP centralizado en Router y listas de control de acceso (ACLs) para restringir el acceso a la VLAN de Servidores.

3. Despliegue de Entornos Cloud Híbridos en AWS & Azure

AWS EC2 Azure VM Security Groups SSH / RDP

Descripción: Aprovisionamiento de servidores en la nube utilizando Amazon Web Services y Microsoft Azure para pruebas de alta disponibilidad.

Configuración:

  • Instancias Ubuntu Server 22.04 LTS en AWS EC2 con emparejamiento de claves SSH.
  • Asignación de IP elástica y configuración de Security Groups abriendo puertos HTTP (80), HTTPS (443) y SSH (22).
  • Creación de una red virtual (VNet) en Azure con subredes pública y privada.

4. Sistema de Gestión de Base de Datos Relacional (MySQL & PL/SQL)

MySQL PL/SQL Triggers Stored Procedures

Descripción: Diseño de modelo Entidad-Relación y desarrollo de scripts de base de datos para la gestión comercial y control de stock.

Características:

  • Creación de tablas normalizadas en 3FN con claves primarias y foráneas.
  • Desarrollo de Triggers para auditoría automática de modificaciones en tablas críticas.
  • Procedimientos almacenados para el cálculo automatizado de facturación mensual.
